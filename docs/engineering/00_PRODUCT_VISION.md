# 00 — Visión de producto (Terramind)

**Problema:** el ciudadano del Valle de Aburrá no sabe "¿cómo está el aire HOY?"
de un vistazo: datos dispersos (SIATA, AMVA), tecnicismos y sin contexto.

**Producto:** plataforma abierta de inteligencia ambiental. Hoy: mapa 3D +
overview AQI + dashboard adaptativo por capas + chat IA anclado a datos.
Mañana: ingesta continua, PostGIS, pronósticos ML y portal de datos.

**Usuarios:** ciudadano (correr o no correr), analista (explorer + CSV),
investigador (metodología + linaje), admin (data health).

**Principios:**
1. Ningún número sin fuente, fecha y bandera de calidad.
2. Dato observado → interpretación → recomendación. Nunca consejo médico.
3. Primero Calidad del Aire excelente; lo demás, capas secundarias.
4. Todo lo gratis y abierto: OpenStreetMap, Open-Meteo, SIATA público.
