# 🔄 TerraMind Data Pipelines & ETL

This directory contains real-time and batch ETL pipelines:

- `sensors_ingestion.py`: Ingestion scripts for public IoT environmental stations (OpenAQ, USGS, national agencies).
- `satellite_sync.py`: Sentinel-2 / Landsat scenes downloader and COG converter.
- `rag_indexer.py`: Academic paper and municipal environmental report chunking & embedding pipeline.
