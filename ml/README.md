# 📈 Terramind Machine Learning Models

This directory houses training routines, inference pipelines, and model evaluation modules:

- `water/`: 7-day water quality indicators forecasting (turbidity, dissolved oxygen).
- `air/`: Spatial Kriging and gradient boosting for PM2.5/NO₂ interpolation.
- `vegetation/`: NDVI time-series canopy loss and deforestation detection.
- `forecasting/`: Solar radiation and wind energy potential forecasting.
