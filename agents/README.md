# 🧠 TerraMind Domain Agents

This directory contains the autonomous domain agent implementations:

- `research/`: Scientific literature search, PDF parser, and pgvector RAG agent.
- `gis/`: Spatial query builder and PostGIS geometry filter agent.
- `water/`: Hydrological basin, runoff, and water quality analysis agent.
- `climate/`: Meteorological time-series and climate risk analysis agent.
- `data/`: Ingestion, statistical validation, and anomaly detection agent.
- `vision/`: Satellite imagery (Sentinel-2, Landsat) optical change detection and YOLO object detector.
