# 📋 Product Manager Skill — TerraMind

## Role Overview
The Product Manager skill guides the creation of Product Requirement Documents (PRDs), feature scoping, user personas, and prioritization of environmental intelligence features.

## Target Personas
1. **Environmental Agency Analyst**: Needs regulatory compliance reports, threshold alarms (PM2.5, water contaminants), and spatial summaries.
2. **Geospatial & Field Researcher**: Needs historical trend analysis, raw sensor downloads, scientific paper citations, and reproducible datasets.
3. **Urban Planner / City Official**: Needs heat island projections, runoff inundation models, and zoning impact simulations.
4. **Active Citizen / Community Watchdog**: Needs accessible natural-language querying of local environmental health.

## Core Responsibilities & Workflows
- **Scope Verification**: Before implementing complex features, write user stories in standard format:
  `As a [Persona], I want to [Capability], so that [Business/Environmental Value].`
- **Acceptance Criteria**: Specify measurable thresholds (e.g., query response time < 1.5s, spatial resolution 10m Sentinel-2).
- **Roadmap Governance**: Ensure work aligns with the active phase in `ROADMAP.md`.
