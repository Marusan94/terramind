# 🤝 Contributing to TerraMind

Welcome! We're excited that you're interested in contributing to TerraMind.

## Getting Started

1. Fork the repository
2. Clone your fork: \git clone https://github.com/YOUR_USERNAME/terramind.git\
3. Create a branch: \git checkout -b feat/your-feature\

## Development Setup

See [README.md](./README.md) for detailed setup instructions.

## Code Style

- **Python**: Black formatter, strict type hints
- **TypeScript**: Strict mode, ESLint
- **Commits**: Conventional Commits format

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Request review from maintainers

## Questions?

Open an issue for bugs, feature requests, or questions.
